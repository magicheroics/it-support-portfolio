# IT Support Portfolio

A documented log of hands-on IT support, networking, and troubleshooting experience gained during my industrial attachment — covering Active Directory management, network diagnostics, hardware repairs, and general technical support.

## About

I'm Eric, an IT student focused on networking and cybersecurity, currently working toward becoming a Network Engineer. This repository tracks real-world tasks and problems I've worked on during my industrial attachment (Sep – Dec 2026), along with the skills gained from each.

## Skills Demonstrated

- **Networking:** Cable crimping/termination, switch diagnostics, connectivity troubleshooting, physical layer fault-finding
- **Active Directory:** Password resets, account management, identity verification procedures
- **Hardware:** POST error diagnosis, CMOS battery replacement, PSU troubleshooting
- **Support:** Printer troubleshooting, equipment setup (e.g. biometrics), spreadsheet/data support, general end-user support

## Structure
/networking - Cabling, switch issues, network troubleshooting

/active-directory - Password resets and account management

/hardware - Diagnostics and repairs (POST errors, PSU, CMOS, etc.)

/support - Printers, equipment setup, general IT support tasks


Each folder contains short write-ups describing the issue, what I did to resolve it, and what I learned.
