# AD Account Password Resets (Recurring Task)


**Frequency:** Ongoing — performed regularly throughout the attachment

## Overview
One of my recurring responsibilities has been resetting passwords for Active Directory (AD) accounts belonging to both students and staff when they are unable to log in.

## What I Do
- Verify the user's identity before making any changes (following verification procedures)
- Reset the AD account password
- Guide the user on setting up a new secure password
- Confirm the account is working after the reset

## Skills Gained
- Active Directory account management
- Password reset procedures
- User identity verification
- Customer/user support skills (students and staff)
- Handling a high volume of repetitive support requests efficiently
