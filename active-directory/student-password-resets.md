# Student AD Account Password Resets (Recurring Task)


**Frequency:** Ongoing — performed regularly throughout the attachment

## Overview
One of my recurring responsibilities has been resetting passwords for students' Active Directory (AD) accounts when they are unable to log in.

## What I Do
- Verify student identity before making any changes (following verification procedures)
- Reset the AD account password
- Guide the student on setting up a new secure password
- Log/confirm the account is working after the reset

## Skills Gained
- Active Directory account management
- Password reset procedures
- User identity verification
- Customer/user support skills
- Handling a high volume of repetitive support requests efficiently
