# Resolving a Loose Main Internet Cable

**Date:** 2026-09-14


## Issue
An office was experiencing a network connectivity issue affecting internet access.

## What I Did
- Diagnosed the network issue by tracing the connection
- Found that the main cable supplying internet to the office was loose
- Reconnected the cable securely
- Confirmed that internet access was restored

## Outcome
Internet connectivity was restored for the office.

## Skills Gained
- Network fault diagnosis
- Physical layer troubleshooting
- Connectivity verification
